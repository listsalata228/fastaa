FASTA OOP documentation

Seq

Класс одной последовательности. Хранит заголовок и последовательность.

Основные свойства: sequence, header, alphabet.

Специальный метод __len__ возвращает длину последовательности. __str__ выводит объект в формате FASTA.

FastaReader

Класс для чтения FASTA-файлов.

Метод is_fasta() проверяет файл, а read() является генератором и возвращает объекты Seq по одному.
